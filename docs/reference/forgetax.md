## 2. 游戏到底在玩什么

### 2.1 玩家目标与题材

玩家是被巨龙控制工坊的铁匠。每天获得有限的剑，通过锻造提高价值，向巨龙交出达到当日需求的贡品，同时把部分剑投入遗物售卖机，构建后续更强的生产能力。玩家需要撑过契约期限；贡品不足会增加巨龙怒气，达到致命阶段就结束本局。**A** [S01][S02]

已发布玩法的主要挑战是经营与概率决策：剑是生产材料、投资成本，也是支付贡税的商品。当前资料不能支持将其描述成以刷怪、走地图、闪避和 Boss 战为主的动作 Roguelike。开发者在 10 月预告中明确将持剑对抗巨龙作为后续内容。**A** [S11]

### 2.2 四层循环

| 层级 | 玩家反复做的事 | 产生的决策 |
| --- | --- | --- |
| 单次挥锤 | 查看下一锤概率 → 挥锤 → 获得结果与遗物触发 | 继续冒险，还是收手保留价值 |
| 单把剑 | 加热 → 强化 → 积攒入神 → 增值、受损、被保护或破碎 | 将这把剑作为主力、贡品、备用品还是商店成本 |
| 单日 | 领取补给 → 购买／替换遗物 → 锻造与商人交易 → 摆放贡品 → 敲铃 | 今天如何兼顾支付能力和明天的成长 |
| 多局 | 图鉴发现 → 成就解锁 → 新遗物进入后续随机池 | 扩充可用构筑，尝试更多剑系与组合 |

前两层包含实时操作；跨日由敲铃结算推动。公开说明支持的主要实时窗口是入神，不能把整个“一天”直接理解成固定秒数的倒计时关卡。**A/B** [S01][C01][C04]

### 2.3 核心张力

以下为 **C：玩法分析**：

1. **已经赚钱的剑也是风险本金。** 更高等级同时提高价值和破碎风险。
2. **投资会消耗生产资料。** 买到强遗物并不等于立刻获利，还要有剑和锻造次数让它生效。
3. **损失可以成为构筑资源。** 不变、损伤、碎剑甚至欠贡，都有对应遗物把它们转成后续收益。
4. **期限让长期成长必须及时兑现。** 储存再多未来收益，如果今天无法保住契约，也可能来不及使用。
5. **收手本身是一项操作。** 把足额贡品先留好，再用余量继续试验，是与无限冲高不同的策略。

## 3. 工坊、操作与一天的流程

### 3.1 场景中的功能点

原作用第一人称工坊承载系统。下表中的功能由官方说明与社区操作指南支持；具体几何布局不作为 2D 复刻的硬性要求。**A/B** [S01][C01]

| 功能点 | 作用 | 重要状态 |
| --- | --- | --- |
| 供剑入口 | 每日接收巨龙提供的基础剑 | 补给数量、起始等级、额外补给 |
| 炉火 | 为剑完成锻造前的加热 | 该剑是否已加热 |
| 铁砧 | 挥锤、显示下一锤结果概率、使用锻造消耗品 | 当前剑、等级、剑值、充能、入神计时 |
| 遗物售卖机 | 投剑换剑币、购买随机遗物、支付金币刷新 | 三个商品位、价格、刷新、持有槽位 |
| 遗物架 | 持有并查看遗物；满槽时丢弃旧遗物 | 八个槽位、触发状态、剩余保护次数 |
| 贡台／窗口 | 摆入准备献出的剑，累计本次贡值 | 台上物品、总值、能否足额支付 |
| 贡铃 | 结束当天并结算 | 当日需求、次日预告、契约进度 |
| 剑架与地面 | 保存未献出的实体剑 | 三个剑架位，以及其他场景中保留的剑 |
| 日历与墙面 | 标示契约日期、商人日、巨龙警告 | 第几日、商人到访、三个警告图案 |
| 幽灵商人 | 定期出售剑和消耗品 | 到访日、库存、金币价格 |
| 图鉴 | 查看剑的外观、遗物和商人物品 | 已发现内容、未解锁轮廓、解锁条件 |

**三格剑架不是总库存上限。** 社区指南记录：未进贡的剑可以保留在剑架、地面、铁砧或手上并跨日保留。官方也专门修复过铁砧上的未献剑在跨日时消失的问题。**A/B** [S02][C01]

### 3.2 常用操作

以下按公开指南记录，属于 **B**；具体消耗品快捷键应以当前游戏界面为准。[C01]

| 输入 | 作用 |
| --- | --- |
| WASD／方向键、鼠标 | 移动与观察 |
| E | 拾取／交互；在铁砧取走剑 |
| 鼠标左键 | 在铁砧挥锤 |
| 鼠标右键 | 离开铁砧并留下剑；持剑时可放下剑 |
| R | 在有回溯次数且仍满足条件时撤回上一锤 |
| X | 对准架上遗物丢弃；部分购买状态可取消 |
| 选择消耗品后使用 | 在铁砧启用相应道具 |

右键放剑、取剑提示、满槽丢弃提示和破碎后的回溯交互都有官方更新说明。**A** [S03][S04][S08][S09]

### 3.3 开局

- 每天的基础供给为三把普通剑；欠贡后次日仍保留这三把基础供给。**A/B** [S05][C12]
- 新局免费从三个候选遗物中选一个；跳过教程仍会出现这次选择，旧局不追溯补发。**A** [S04]
- 社区记录初始候选池有八件；按 10 月 7 日官方替换修正后，可作为候选的名单为：弯钉、黑色绳结、验货印章、封印石、开裂的接合片、封印之心、幸运炭、送葬人的圣杯。完整八件名单是 **B＋官方局部修正**，并非官方逐项公布的当前完整清单。[C07][S06]
- 社区记录免费三选一不能刷新，选一后另外两件消失；第 2 天起进入常规付费商店。**B** [C07]

### 3.4 一天的实际流程

1. **读局面**：确认当日贡额、已有怒气、保留的剑、金币、剑币和商店。
2. **分配剑**：决定哪些用于锻造，哪些换遗物，哪些保留作为备用贡品。
3. **完成加热**：普通剑先放入炉火；社区记录加热对本剑持续有效，不随每锤消耗。
4. **在铁砧锻造**：每锤后同时查看实际价值、等级、保护和下一锤概率。
5. **构筑与交易**：按资源购买遗物；遇商人日可补剑、买保护、回溯或充能物品。
6. **准备贡品**：将选中的剑放进贡台，检查台上总值。敲铃前可以取回。
7. **敲铃结算**：献出的是贡台上的剑；足额则正常推进，欠额则增加怒气。
8. **进入次日或结束本局**：未献出的剑继续保留；结算补给、相关遗物和成就。

这是基于公开规则组织的玩家流程，**不是强制购买顺序**。玩家可以在一天内多次往返铁砧、商店和贡台。**A/B；步骤组织为 C** [S01][C12]

## 4. 三种资源与价值流转

### 4.1 资源不能互相混算

| 项目 | 是什么 | 获得方式 | 消耗／用途 |
| --- | --- | --- | --- |
| **实体剑** | 场景中实际存在的物品 | 每日补给、商人、复制、补给遗物 | 锻造、进贡、投入售卖机 |
| **剑币／遗物商店信用** | 购买遗物的专用额度 | 通常一把剑换一币；部分遗物直接给币 | 支付遗物价格 |
| **金币 G** | 可储存的商店货币 | 献出剑的价值结算为金币、碎剑收益等 | 刷新遗物商店、购买商人物品 |
| **剑值／贡值** | 某把剑或贡台物品的估值 | 等级、大成功与遗物共同决定 | 用来判断当天贡品是否足够 |

通常把一把普通实体剑投入售卖机只获得 **1 剑币**，与该剑等级和金币价值无关。贡台的剑在结算时按价值转化成金币；社区记录即使欠贡，已交出的部分也会返还相应金币。已有金币余额不能直接充当台上的当日贡品。**B** [C12][C05]

### 4.2 对策略的影响

以下为 **C：分析**：

- 一把值 100,000 G 的剑，如果仍只换 1 剑币，其作为商店材料的机会成本远高于一把 +0 剑。
- 买遗物既消耗“购买力”，也减少可供锻造的剑数。生产能力和投资成本在同一物品上竞争。
- 进贡同时完成两件事：保持契约、获得金币。超额献剑可以形成商人预算，但会失去可留到明天的实体库存。
- “金币很多”“所有剑合计很贵”“贡台已经够值”是三个不同状态，界面和结算必须分别表达。
- 直接给剑币的征税牌与直接给实体剑的追加供货许可，不能都实现成“库存 +1”。

## 5. 剑的状态、类型与演化

### 5.1 一把剑不只是一个强化等级

为解释玩法，至少应区分这些状态。字段划分是 **C：复刻建模建议**，其背后的现象见后文资料：

| 状态 | 为什么需要 |
| --- | --- |
| 当前等级 | 决定当前等级价值和基础破碎风险 |
| 历史最高等级／已达外观 | 损伤降级后外观不一定退回；图鉴按发现记录 |
| 剑系、普通供给路线与隐藏分支 | 决定中高等级演化方向 |
| 是否加热、是否锻造过 | 锻造前置条件，以及“下一把未经锻造 +0 剑”的继承条件 |
| 基础价值、固定加值、持久倍率 | 同等级的剑可以有不同价值 |
| 历史最高剑值 | 圣杯按最高价值回收残骸贡品 |
| 入神充能及状态 | 充能属于该剑，取下后再放回不能简单清零 |
| 各种本剑层数 | 损伤减破碎、成功签积累、待兑现升级等 |
| 保护使用情况 | 每剑一次保护与每日一次保护的重置范围不同 |
| 上一锤结果、连锁计数 | 多件遗物依赖前后结果或连续次数 |

### 5.2 普通供给剑

**B：社区数据**记录，普通剑基础价值为 **320 G**，初始通常为 +0。[C03]

普通剑在 +0、+2、+4 共有早期外观；到 +6 按供给路线分成三类方向，在 +10 由该路线与预先确定的二选一隐藏分支组合成六条剑系。每天基础三剑按三条路线打乱分配，因此普通三剑供给包含每条路线各一把。商人购买的普通剑则随机获得路线和分支。[C09]

这里的“分支”不是玩家在 +10 弹窗主动选职业；公开数据库描述其在供剑时已经决定。若要改变为玩家选路，属于本项目的规则改动。

### 5.4 等级上限与外观上限

- 当前强化上限为 **+99**，从旧版 +30 提高。**A**
- **+20 是最终外观节点，不是当前强化上限。** +20 以上保留最终外观。**A** [S04]
- 社区记录普通演化在偶数等级更新外观，外观由历史达到的等级决定，损伤不会必然缩回旧外形。**B** [C09][C02]
- 这使玩家同时追求“活过契约”“打造高值剑”“发现全外观”“完成 +20 掌握成就”和“挑战 +99”，这些目标不应混成一个通关条件。

| 挥锤前等级 | 破碎概率约值 | 挥锤前等级 | 破碎概率约值 |
| --- | ---: | --- | ---: |
| +0 | 0.0% | +8 | 41.8% |

| +2 | 5.9% | +10 | 46.7% |

### 6.3 抽签权重不等于固定百分比

**B：社区对概率系统的描述**：

- 基础五类签数按“破碎、损伤、不变、成功、大成功”分别为 **9、2、5、12、2**。
- 破碎堆再接受等级权重，因此不能用 9÷30 得出所有等级固定 30% 破碎。
- 最终抽取被离散为 1,000 格；显示百分比可能包含取整差异。
- 添加成功签也会稀释其他结果占比；“+4 成功签”不是“成功率 +4 个百分点”。[C02]

**A：官方明确的相对减免**：若破碎概率为 40%，降低 15% 后为 **40% × 0.85＝34%**，不是 25%。[S04]

由此可区分三类效果：

| 效果类别 | 例子 | 对模型的要求 |
| --- | --- | --- |
| 增减／搬运签 | 弯钉、铁箍、砥石、荆棘砝码 | 改抽签权重后重新归一化 |
| 相对修改破碎概率 | 黑色绳结、龙鳞钳、接合片 | 不按百分点直接相减 |
| 抽到后保护／改写结果 | 铁丝缠鞘、不倒基石、凤凰之灰 | 与原始抽签分开处理 |

官方说明墙面签数和铁砧最终概率承担不同信息功能；当前剑的加签、减签、临时加成应能区分。**A** [S06]

### 6.4 复刻概率模型的推导边界

下面是 **C：由公开权重描述推导的候选模型**，不能当作原作源代码：

~~~text
令 p0(L) 为无遗物时等级 L 的基础破碎概率。
基础非破碎签总数为 21，破碎签为 9。

等级破碎权重：
    k(L) = p0(L) × 21 / [9 × (1 − p0(L))]

修改签数后：
    破碎权重 = 修改后的破碎签数 × k(L)
    其他结果权重 = 各自修改后的签数
    将五类权重归一化

再应用相对减破碎、入神和临时道具等规则；
最后离散化并处理保护、结果触发。
~~~

这一模型解释了“同样一张破碎签在不同等级的意义不同”。例如，镰刀与锤子把基础签都设为 5 后，也不能直接认定任意等级五类结果各 20%。社区攻略中“3/23 就是固定破碎率”的口算忽略了等级权重。

**尚不能由公开说明确定**：所有修正的准确先后、每一步的整数截断、多个保碎效果的消费顺序、临时道具与强制改写的优先级。实现时应将它们独立配置并通过实机样本校准，不能用上面的候选公式掩盖未知项。

## 7. 剑值、等级与大成功

### 7.1 价值结构

社区数据库给出的概念公式是：**B** [C03]

~~~text
剑值 ≈ round((基础价值 × 1.5^当前等级 + 固定加值) × 各种价值倍率)
~~~

三种收益应分别建模：

| 收益 | 例子 | 后续升级时的行为 |
| --- | --- | --- |
| 基础价值增长 | 炭粉袋、黄金齿轮、永恒之种 | 跟随 1.5 的等级次方放大 |
| 固定加值 | 验货印章、围裙、镇纸、伤痕保值 | 不因为升一级就自动变成新的基础价值 |
| 倍率 | 铁印、裂钟、龙之心、凤凰之灰的折损 | 按自身条件和持续范围作用 |

特别要区分“遗物仍在架上时提供的倍率”和“已经积累在剑上的倍率”。公开资料对复杂组合的全部结算顺序仍不足，不能仅用总价值反推所有持久状态。

### 7.2 纯普通成功路径的参考价值

下表是 **B：基础 320 G、无遗物、无大成功附加收益**的等级路径；同等级的真实剑可能更贵。高等级整数值依赖取整口径。[C03]

| 等级 | 普通剑参考价值 |
| --- | ---: |
| +0 | 320 G |
| +1 | 480 G |
| +2 | 720 G |
| +3 | 1,080 G |
| +4 | 1,620 G |
| +5 | 2,430 G |
| +6 | 3,645 G |
| +10 | 18,453 G |
| +12 | 41,519 G |
| +15 | 140,126 G |
| +20 | 1,064,082 G |

首日基础贡额为 1,800 G，因此一把普通 +5 可支付；普通 +4 与 +2 合计 2,340 G 也可支付。这是说明“组合总值比统一冲某个等级更重要”的例子，不是保底锻造路线。**B／决策解释为 C** [C12]

### 7.3 大成功为什么不等于普通成功两次

官方将大成功价值倍率从 3 倍调整为 **2.5 倍**。普通两次 +1 的等级因子为 1.5²＝2.25，因此大成功有额外的价值优势。**A/B** [S04][C03]

社区给出的无遗物例子：普通成功升到 +8 后，大成功到 +10，约值 20,503 G；仅靠普通成功到 +10 则约 18,453 G。说明等级相同，成长历史仍会影响价值。[C03]

**不能先按 +2 算 2.25 倍，再额外乘 2.5 倍。** 这会把一次大成功错误结算成 5.625 倍。带固定加值、额外升级、等级上限时的完整内部计算还需复测。

### 7.4 损伤不意味着所有成长归零

损伤主要降低当前等级，部分固定加值、已积累倍率与外观发现可以保留。裂冠、铁梳还会将损失转成固定价值。因此“等级 −1”不等价于“总剑值简单除以 1.5”，更不等价于“剑已报废”。**B** [C13]

## 8. 入神 Frenzy：积攒风险，兑现安全窗口

### 8.1 基本规则

| 项目 | 当前资料支持的规则 | 证据 |
| --- | --- | --- |
| 充能归属 | 属于同一把剑；取下再放回仍保留 | B [C01] |
| 普通充能 | 入神外每次挥锤通常 +1 点 | B [C04] |
| 触发门槛 | 累计到 10 点后，由**下一锤**启动 | A/B [S01][C04] |
| 基础时长 | 4 秒实时窗口 | B [C04] |
| 核心保护 | 移除破碎结果 | A/B [S01][C04] |
| 仍可能发生 | 损伤、不变、成功、大成功 | B [C04] |
| 启动与再充能 | 启动后清空充能，入神中不继续按普通规则积攒 | B [C04] |
| 基础速度 | 入神本身已不再额外提高基础挥锤速度 | A [S04] |

**门槛不是“连续十次普通成功”。** 不变和损伤也能推进普通挥锤计数，部分遗物还额外充能。把切换剑理解成“全局充能清零”同样不准确：充能是每把剑自己的状态。

### 8.2 构筑如何改变窗口

- 余烬吊坠提高本剑首锤充能；裂开的腕表、锁链沙漏分别从损伤、不变获得额外充能。
- 寒星碎片直接增加 3 点充能；继承遗物可让新剑带着充能开始。
- 红沙漏延长 1 秒，不灭灯芯延长 2 秒。
- 磨秃的握柄提高通用速度；入神风箱只提高入神速度；皮环只作用于入神外。
- 完美魔力核增加入神大成功签；玻璃沙漏使入神大成功通常合计升 3 级；铃铛项圈按窗口内每锤加值。

以上具体数值为 **B**，对应独立来源见附录 A；继承加成与基础速度变化另有官方支持。[S04][S05]

社区记录基础挥锤间隔约为 0.64 秒除以速度系数；基础 4 秒窗口在理想节奏下最多约 7 锤，包含启动那一锤。动画、尤其大成功动作和帧率会使实际次数减少。该数字是**理论上限参考 B**，不能要求玩家或 2D 实现一定达到固定七锤。[C04]

### 8.3 玩家决策

以下为 **C：分析**：

入神前的十次充能过程承受普通风险，安全窗口只保护已启动后的锤击。玩家需要决定：值得为触发窗口继续冒几锤风险，是否先用充能／保护道具，以及窗口结束后是否立即停手。入神“不会碎”也不能推导成“每锤必升”。

## 9. 遗物商店、槽位与构筑

### 9.1 获得和替换遗物

**B：社区记录**：

- 遗物架有 **8 个槽位**，大部分遗物在本局持续生效。
- 第 2 天起商店通常显示 **3 个付费候选**。
- 用剑币买遗物，用金币刷新；物品按最早天数、稀有度和解锁状态进入候选池。
- 满槽时不能直接买第九件，需先丢弃旧遗物；通常没有退款。[C01][C07]

官方确认满槽丢弃提示、保护遗物剩余次数和充能状态的显示，并提高了第 2—6 天部分恢复、防御遗物的出现权重。最早出现天数和解锁条件仍然适用。**A** [S05][S09]

这意味着“候选池中同稀有度物品平均概率相同”不能直接作为准确规则。第 2—6 天的特殊倾向还会改变具体物品的出现率。

## 10. 进贡、怒气、契约与无尽

### 10.1 进贡如何结算

- 判断的是**贡台上献出物品的合计价值**，不是剑的数量，也不是所有库存总值。**A/B** [S01][C05]
- 敲铃前可取回贡台上的剑；敲铃后这些剑被交出。**B** [C12]
- 献出价值转成金币；欠额也会结算已献出的价值。**B** [C05]
- 普通碎剑没有正常贡值，但圣杯等残骸机制可产生贡品。**A/B** [S05][C05]

### 10.2 巨龙怒气与容错

通常每次欠贡增加一档怒气，达到第三档致命阶段则结束本局。三次是累计的警告预算，不能理解为“连续三天欠贡才失败”。**A/B** [S02][C05]

### 10.6 降低贡额

- 减税密函：当日需求降低 10%。**B**，见附录条目。
- 王室的零钱：将超额部分的 30% 抵扣下一日要求，最多降低下一日贡额的 30%。抵扣上限有官方确认。**A/B** [S04]

## 12. 破碎、保护、残值、继承与回溯

### 12.1 保护不是一种统一效果

| 机制 | 例子 | 后果 |
| --- | --- | --- |
| 降低抽到破碎的概率 | 接合片、龙鳞钳、黑色绳结 | 仍可能抽到破碎 |
| 破碎结果改损伤 | 巨人脊骨、铁丝缠鞘、不倒基石 | 剑活着，接着处理损伤及相关触发 |
| 取消破碎但付价值代价 | 凤凰之灰 | 每剑一次，保留等级但损失 40% 剑值 |
| 单锤挡碎 | 裂纹龙鳞 | 对指定下一锤生效，没抽到破碎也会消耗 |
| 结果之后撤回 | 悔恨发条／回溯 | 回到上一锤前，而非另行掷一次新的锻造结果 |

具体限制见附录和物品独立来源，属于 **A/B**。实现时不能把它们全部写成“失败时扣一层护盾”。

### 12.2 损伤触发的两个重要例外

**A：官方明确**，即使剑处在 +0，或损伤的掉级被保护挡住，只要发生的是损伤结果，相关损伤触发仍可生效。[S04]

但巨人脊骨的公开描述另有自循环限制：它把一次破碎改成损伤后，该次损伤**不能给它自己重新充能**。不能据“仍可触发损伤遗物”推出巨人脊骨无限自充。[附录 A 巨人脊骨](#附录-a公开遗物目录)

### 12.3 真正破碎后的不同收益

- 圣杯按该剑**历史最高值的 30%**形成残骸贡品。
- 筛灰网直接给金币。
- 骨灰王之鞘给本局永久签。
- 殡葬师的账簿给次日额外实体剑。
- 继承类遗物把部分强化转给符合条件的新剑。
- 被保住、没有真正碎掉的剑，不应自动视为触发了所有“碎剑收益”；准确例外需实测。

前五项分别有官方或独立社区条目支持；最后一项是 **C：基于条件措辞的实现原则**，不是已确认的全局事件顺序。[S04][S05]

| 持有遗物 | 传递的强化比例 | 继承时附带的入神充能 |

官方曾修复通过撤销或重新载入重复获取金币、签等问题；又修复过碎剑后立刻按 E 会失去回溯机会的问题。后续还明确，撤销复制只取消那一次效果产生的复制剑。**A** [S04][S08][S10]

### 14.1 一条损伤循环如何拆解

以围裙、接合片、誓言、玉玺为例：

1. 损伤结果发生后，围裙增加固定价值。
2. 接合片给这把剑累积相对减破碎。
3. 玉玺增加“下次大成功可兑现的额外等级”。
4. 誓言独立判断 70% 概率返一级。
5. 等待出现大成功后兑现蓄层，重新判断实际剑值与风险。
6. 配入巨人脊骨后，还需要跟踪其保护是否已充好、是否已消费。

这是**功能分工的说明，不主张原作内部以此顺序结算**。保护之间的优先级、返级与价值快照顺序仍属待核实项。

深海之珠需要先把海产剑锻至 +20 解锁，且社区记录第 7 天起才进入商店、费用 4 剑币；它不能被当作每局开场必有的损伤流前提。

### 14.2 为什么成熟构筑也可能输

- 对这把剑的层数、保护和实际价值判断错误。
- 买新遗物时花掉全部可用剑，构筑没有生产材料。
- 把未兑现玉玺等级当成已经存在的贡品。
- 入神结束后继续按“不会碎”的假设挥锤。
- 丢弃唯一保护以追求更高倍率，令整套收益无法稳定兑现。
- 把玩家攻略中的幸运样本当成每局都能达到的概率保证。

## 15. 风险判断与局内策略节奏

本节均为 **C：分析**。

### 15.1 继续一锤的价值

最简单的单锤比较可以写成：

~~~text
继续锤击的期望价值
    = Σ(各结果概率 × 该结果结算后的实际可用价值)

但还必须另外考虑：
    碎掉后能否交今天的贡品
    还有多少备用剑与补救物品
    是否能在未来几锤进入入神
    此锤会增加哪些永久签、继承或保护
    当前主力被献出后，后续生产是否还成立
~~~

总剑值的期望高，并不自动意味着存活概率高。如果这把剑是唯一支付来源，损失的不是一个金币数字，而是当天的支付能力。

例如把每锤破碎率暂时固定为 40%，无保护连续三锤都不碎只有 0.6³＝21.6%。实际游戏每锤等级和效果会变，这只是说明风险累积，不能代替当前局面的精确概率。

### 15.2 三个阶段

| 阶段 | 主要任务 | 应观察的资源 |
| --- | --- | --- |
| 早期 | 形成能交贡、能继续买遗物的基础循环 | 每把剑的用途、低费生存件、首批商人预算 |
| 中期 | 补齐收益、保护、充能／恢复，逐步完成八槽构筑 | 核心是否协同、是否留有备用剑、解锁件是否可出现 |
| 后期与无尽 | 将成熟循环转成高值剑、全剑系发现与更高等级 | 本局永久签、复制与供给、巨额数值、存放和回溯状态 |

阶段划分是理解节奏的方法，不是原作存在三张固定地图或三个章节的证据。

3D 物理碰撞和绕房间走动可以简化，但“先加热再锻造”“剑同时承担三种用途”“主动敲铃推进日程”这些关系会直接影响玩法。

### 16.2 状态结算建议

建议显式保存原始抽签结果和最终有效结果，并把一锤组织为可检查的事务：

~~~text
确认能挥锤
→ 保存可回溯快照
→ 判断是否由本锤启动入神
→ 计算下一锤分布
→ 抽取原始结果
→ 处理保护／结果改写
→ 结算等级、价值与各类触发
→ 处理真正破碎、继承、复制和奖励
→ 更新充能、下一锤状态、图鉴与成就
→ 刷新界面
~~~

这只是实现建议。原作所有遗物的严格顺序没有公开完整说明，尤其不能凭这个顺序决定尚未验证的边界结果。

每日结算同样建议按“冻结献出列表 → 统计贡值 → 结算金币与足额状态 → 处理怒气及救命 → 判断存活与契约完成 → 生成下一日状态”组织，并防止重复点击造成重复支付或重复奖励。

### B.3 来源冲突的处理原则

1. 同一机制有官方后续热修时，优先采用后续热修。
2. 官方公告没有列出的完整配置标为社区记录，不将“未在公告提到”写成“不存在”。
3. 公开预告只用于说明未来方向，不据此添加现行战斗系统。
4. 不把不同版本的低税额、旧遗物效果和新遗物池拼成一个不存在的版本。
5. 社区“必通关”“稳定无限”“固定概率”的说法不作为规则；保留可核对的效果与数值。
6. 官方及社区均未说明的结算顺序保留为待验证项，2D 建议使用独立标记。
